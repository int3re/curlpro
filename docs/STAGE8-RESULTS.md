# Этап 8 — дистрибуция

Дата: 2026-09-01. Подготовка к выпуску: CI и колёса.

## Три рабочих процесса

| Файл | Когда | Зачем |
|---|---|---|
| [test.yml](../.github/workflows/test.yml) | push, PR | `go vet`, Go-тесты, сборка `c-shared`, Python-тесты |
| [validate-profiles.yml](../.github/workflows/validate-profiles.yml) | **еженедельно** + при правке профилей | сверка отпечатков с эталоном |
| [wheels.yml](../.github/workflows/wheels.yml) | тег `v*` | колёса под 5 платформ |

**Валидация по расписанию, а не только на push** — это главное. Профили
протухают не от коммитов, а от обновлений браузеров и изменений на стороне
сервисов проверки. Без расписания расхождение всплыло бы у пользователя.

В `test.yml` сборка `c-shared` вынесена отдельной целью: пакеты `internal/h3`
и `internal/client` тестами не покрыты, и поломка в них иначе всплыла бы
только при выпуске.

## Колёса собираются на каждой платформе

Кросс-компиляция здесь не работает: `cgo` требует тулчейн целевой платформы.
Поэтому матрица из пяти сборок, каждая на своей ОС:

```
ubuntu-latest      amd64  manylinux_2_28_x86_64
ubuntu-24.04-arm   arm64  manylinux_2_28_aarch64
macos-13           amd64  macosx_10_15_x86_64
macos-latest       arm64  macosx_11_0_arm64
windows-latest     amd64  win_amd64
```

Тег платформы проставляется явно (`wheel tags --platform-tag`): колесо содержит
нативный код и не является universal, а `python -m build` этого не знает.

Каждая сборка заканчивается проверкой: колесо ставится, профили находятся,
делается живой запрос и печатается JA4. Собрать нерабочее колесо и заметить
это после выпуска — худший вариант.

## Профили едут внутри колеса

Библиотека без профилей бесполезна, поэтому `profiles/` копируется в пакет
на этапе сборки, а `ensure_loaded()` подхватывает их при создании сессии.
После `pip install` работает сразу:

```python
import curlpro
with curlpro.Session("chrome-151-windows") as s:   # профили уже загружены
    print(s.get("https://tls.browserleaks.com/json").json()["ja4"])
```

При запуске из репозитория вложенного каталога нет — тогда профили грузит
вызывающий, как раньше. Обратная совместимость сохранена.

                 -baselines reference/baselines -pause 2s -update
