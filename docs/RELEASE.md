# Выпуск версии

Пакет собирается и выкладывается рабочим процессом
[.github/workflows/wheels.yml](../.github/workflows/wheels.yml) по тегу `v*`.

## Что происходит по тегу

1. **build** — колёса на пяти платформах: Linux x86-64 и arm64, macOS Intel
   и Apple Silicon, Windows x86-64. Каждая собирается на своей машине: cgo
   без тулчейна целевой платформы не кросс-компилируется.
2. Каждое колесо проверяется на месте: ставится и делает живой запрос
   к `tls.browserleaks.com`, сверяя JA4. Битое колесо не доедет до индекса.
3. **sdist** — исходный архив для платформ, которых нет в списке: он соберёт
   нативную часть сам, если у пользователя есть Go и компилятор C.
4. **publish** — выкладка на PyPI доверенным способом.

## Что нужно настроить один раз

Публикация идёт **доверенным способом** (trusted publishing): PyPI проверяет
подпись самого запуска в GitHub, и хранить токен в секретах репозитория
не нужно вовсе — красть будет нечего.

1. Завести проект на PyPI и в его настройках добавить издателя:

   | Поле | Значение |
   |---|---|
   | Owner | `int3re` |
   | Repository | `curlpro` |
   | Workflow | `wheels.yml` |
   | Environment | `pypi` |

2. В настройках репозитория создать окружение `pypi` и включить у него
   обязательное подтверждение (*Required reviewers*). Выкладка в общий
   индекс необратима: занятую версию не освободить, и один неверный тег
   иначе стоил бы номера навсегда.

Имя `curlpro` на PyPI на 2026-09-04 свободно.

## Как выпускать

```bash
# 1. Поднять версию в python/pyproject.toml
# 2. Убедиться, что всё зелено
go test ./internal/... && cd python && python -m pytest tests -q

# 3. Тег и отправка
git tag v0.2.0
git push origin v0.2.0
```

Дальше рабочий процесс соберёт колёса, дождётся подтверждения окружения
и выложит пакет.

## Версия нативной части

У библиотеки есть своя версия ABI (`Version` в [lib/curlpro.go](../lib/curlpro.go)
и `REQUIRED_VERSION` в `python/curlpro/_ffi.py`). Она **не** совпадает с версией
пакета и поднимается тогда, когда Python начинает зависеть от нового экспорта
или поля конфигурации. Без этого старая библиотека молча игнорирует незнакомые
поля: опция передаётся, но не действует — и это выглядит как ошибка логики,
а не как устаревшая сборка. На такой ловушке однажды был потерян час прогонов
не того кода.
